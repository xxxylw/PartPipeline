# Phase 6 Plan: HoloPart Integration

<objective>
Add a HoloPart runner and CLI command that runs upstream HoloPart inference on `bridge/prepared_parts.glb`, writes `holopart/output.glb`, records logs, and updates the run manifest.
</objective>

<context>
Phase 5 already converted SAMPart3D output into a HoloPart-compatible multipart GLB. HoloPart `prepare_data(..., device="cpu")` loaded the real prepared GLB successfully with 34 parts. Phase 6 therefore owns model invocation, output collection, error handling, and manifest recording.
</context>
