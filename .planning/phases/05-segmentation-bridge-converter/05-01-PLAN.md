# Phase 5 Plan: Segmentation Bridge Converter

<objective>
Build a bridge converter that takes the source/staged GLB and SAMPart3D `mesh_1.0.npy`, optionally merges small fragmented parts into neighboring larger parts, and writes a HoloPart-compatible multipart GLB plus manifest artifacts.
</objective>

<context>
Phase 4 now produces a real SAMPart3D result:

- staged GLB: `outputs/runs/<run>/sam/<run>.glb`
- selected mask: `outputs/runs/<run>/sam/mesh_1.0.npy`

HoloPart expects a GLB scene with one mesh geometry per segmented part. Its README uses `trimesh.load(..., force="mesh")`, `mesh.submesh([mask == part_id], append=True)`, and `trimesh.Scene(mesh_parts).export(...)`.

The `part` environment already has `numpy` and `trimesh`, so Phase 5 should avoid new dependencies.
</context>

## Task 3: Implement Mask Validation And Small-Part Merge

type: tdd

files:

- `src/partpipeline/bridge.py`
- `tests/test_bridge.py`

action:

1. Implement `validate_face_mask(mesh, mask)`:
   - mask must be one-dimensional
   - mask length must equal `len(mesh.faces)`
   - mask labels must be integer-compatible
2. Implement part statistics:
   - face count
   - face ratio
   - area if `mesh.area_faces` is available
3. Implement topology adjacency:
   - build edge-to-face map from `mesh.faces`
   - count label-to-label shared boundaries
4. Implement small-part selection:
   - small if `face_count < min_faces_per_part`
   - or `face_count / total_faces < min_area_ratio` if ratio threshold is enabled
5. Implement merge:
   - merge small part into neighboring non-small part with highest shared boundary count
   - fallback to nearest centroid non-small part only when no topological neighbor exists
   - record source label, target label, method, reason, face count, and boundary count or distance

verify:

```bash
PYTHONPATH=src /home/rui/miniconda3/envs/part/bin/python -m unittest tests.test_bridge
```

acceptance_criteria:

- Face-count mismatch raises a clear error.
- A synthetic tiny part sharing a boundary with a larger part is relabeled to that larger part.
- A no-neighbor synthetic tiny part uses the centroid fallback.
- Original mask arrays are not mutated in place.
